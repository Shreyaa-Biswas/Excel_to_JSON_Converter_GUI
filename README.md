# Excel_to_JSON_Converter_GUI

A simple Python utility to convert Excel files (.xlsx) to JSON format, with support for multiple sheets and customizable output.
Features

1. Converts all sheets in an Excel file to a single JSON array
2. Handles datetime columns by converting them to strings
3. Properly handles NaN/null values
4. Optional sheet name tracking in output
5. Progress bar for large files
6. Pretty-formatted JSON output
